- API 认证
- 所有 API 请求都需要携带有效的访问令牌
- Authorization: Bearer <your-access-token>
- Token 类型
- Session Token：浏览器完成 Privy 登录后由后端签发，用于当前 Web 会话。
- Sandbox Token：在 Tokens 页面或受限 access-token 接口签发，仅用于 sandbox。
- Service Account Token：面向租户内机器身份，适合长期自动化任务。
- 命令行接入方式
- 命令行不支持直接完成 Privy 登录。请先在 Web 端获取 sandbox token，再直接调用 sandbox 命令。
- toani --base-url https://your-api.example.com --token <SANDBOX_TOKEN> sandbox stats
- POST /api/v1/auth/access-token
- 从当前会话签发受限 sandbox token（仅支持 credential:read + credential_ids）
- 请求体: { "scopes": ["credential:read"], "credential_ids": ["cred_123"], "ttl_seconds": 1800 }
- 响应体: { "access_token": "v4.local....", "token_id": "uuid", "granted_scopes": ["credential:read"], "credential_ids": ["cred_123"], "expires_in": 1800, "token_type": "Bearer" }
