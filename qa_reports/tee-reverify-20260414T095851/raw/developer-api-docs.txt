API authentication
All API requests require a valid access token.
Header format
The SDK and tester use the same authentication rules so you can reuse flows during local validation and integration debugging.
Authorization: Bearer <your-access-token>
Token types
Session Token: minted by the backend after the browser completes Privy login and used for the active web session.
Access Token: minted from the current bearer token with a reduced scope set and TTL for restricted automation calls.
Service Account Token: machine identity token for tenant-scoped automation.
Token format
Uses the PASETO v4.local format, which is safer than JWT and supports symmetric encryption.
CLI onboarding

The CLI does not include browser login. Obtain a bearer token first, then call sandbox commands directly with flags or environment variables.

toani --base-url https://your-api.example.com --token <BEARER_TOKEN> sandbox stats
