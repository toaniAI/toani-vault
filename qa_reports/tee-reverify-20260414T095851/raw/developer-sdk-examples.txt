SDK installation
Quick start for the Toani Vault TypeScript/JavaScript SDK
npm install @toani/vault-sdk
Copy

The SDK source lives at sdk-typescript/ in the project root and can be linked locally for development and testing. The package has been migrated from @credbridge/sdk to @toani/vault-sdk. The old package name is deprecated.

npm link ../../sdk-typescript
Basic example
End-to-end sandbox session example
Copy
import { ToaniVaultSDK } from '@toani/vault-sdk';

// Initialize the SDK (Note: CredBridgeSDK is deprecated, please migrate to ToaniVaultSDK)
const sdk = new ToaniVaultSDK({
  baseUrl: 'https://your-api.example.com',
  token: 'v4.local.your-token-here',
  timeout: 30000,
});

// Create a sandbox session
const session = await sdk.sandbox.createSession({
  service_id: 'github-prod',
  original_intent: 'collect public repo metadata'
});

// Execute browser actions inside the sandbox
await sdk.sandbox.navigate(session.id, 'https://github.com/openai');
await sdk.sandbox.waitForSelector(session.id, 'main');
const title = await sdk.sandbox.getText(session.id, 'title');
console.log('Page title:', title);

// Close the session
await sdk.sandbox.closeSession(session.id);

Error handling
Sandbox-focused error-handling example
Copy
import { CredBridgeError, CredBridgeErrorCode } from '@toani/vault-sdk';

// Note: Error class names remain CredBridgeError and CredBridgeErrorCode
// Package migrated from @credbridge/sdk to @toani/vault-sdk
try {
  await sdk.sandbox.createSession({
    service_id: 'blocked-service',
    original_intent: 'run restricted action'
  });
} catch (error) {
  if (error instanceof CredBridgeError) {
    switch (error.code) {
      case CredBridgeErrorCode.NotFound:
        console.error('Sandbox session not found');
        break;
      case CredBridgeErrorCode.Unauthorized:
        console.error('Token expired. Sign in again.');
        break;
      case CredBridgeErrorCode.Forbidden:
        console.error('Insufficient permissions (missing sandbox scope).');
        break;
      default:
        console.error('API error:', error.message);
    }
  }
}
Sandbox browser automation
Run web operations securely inside a TEE-isolated environment
Copy
import { ToaniVaultSDK } from '@toani/vault-sdk';

const sdk = new ToaniVaultSDK({
  baseUrl: 'https://your-api.example.com',
  token: 'v4.local.your-token-here',
});

// 1. Create a sandbox session
const session = await sdk.sandbox.createSession({
  credential_id: 'your-credential-id',
  security_policy: {
    max_memory_mb: 512,
    max_cpu_percent: 50,
    max_execution_time_seconds: 300,
    allowed_domains: ['example.com'],
    allow_file_downloads: false
  }
});

console.log('Session created:', session.id);

// 2. Navigate to a page
await sdk.sandbox.navigate(session.id, 'https://example.com/login');

// 3. Fill the form and sign in
await sdk.sandbox.fill(session.id, '#username', { $credential: 'username' });
await sdk.sandbox.fill(session.id, '#password', { $credential: 'password' });
await sdk.sandbox.click(session.id, '#login-btn');

// 4. Wait for the page to load
await sdk.sandbox.waitForSelector(session.id, '.dashboard');

// 5. Extract data
const data = await sdk.sandbox.getText(session.id, '.balance');
console.log('Balance:', data);

// 6. Capture a screenshot
const screenshot = await sdk.sandbox.takeScreenshot(session.id, {
  full_page: true,
  quality: 90
});

// 7. Export data
const exportData = await sdk.sandbox.exportData(session.id, {
  format: 'json',
  selector: '.data-table',
  redact_sensitive: true,
  apply_watermark: true
});

// 8. Close the session
await sdk.sandbox.closeSession(session.id);
Security features
TEE trusted execution protects session runs.
An AI review engine automatically detects suspicious actions.
Exports are automatically redacted and watermarked.
Resource limits cover CPU, memory, and execution time.
Linux Namespaces and Seccomp provide sandbox isolation.
