Technical architecture
Toani Vault system component overview
Backend service (Rust + Axum)
A high-performance async HTTP service that handles credential management, token auth, sandbox orchestration, and audit logging.
TEE runtime
An isolated secure enclave for cryptographic operations and sensitive key management.
Storage layer
PostgreSQL stores credential metadata, immudb stores audit logs, and Redis stores cache and session data.
Vault integration
HashiCorp Vault provides dynamic key management, secret engines, and access control.
Supported credential types
Username & Password

The most common credential type for website logins and application authentication.

API Key

Server-side API authentication with optional key + secret pairing.

OAuth Token

OAuth 2.0 / OIDC token management with refresh support.

Session Cookie

Web session cookie management with secure flags and expiration policies.

KYC Document

Identity document storage for compliant KYC workflows.

Client Certificate

Client TLS certificate management with mutual authentication support.
