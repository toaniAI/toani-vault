# Toani.ai 视觉语言提炼与 CredBridge 前端风格指导

## 1. 文档目的

基于 Figma 文件 `Toani.ai`（`y0iO96e4PpGQOLJlLEWJAv`）中可访问节点，提炼可落地的 UI 设计语言，用于指导 CredBridge 的前端风格升级。

本次分析样本包含：

- 参考风格拼贴区（`1:2`）
- 主视觉材质节点（`57:2`）
- 全文件结构元数据（含 LOGO 方案/定稿与材质素材区）
- Toani 官网页面截图（Hero、能力说明、问题清单、产品卡、指标区、CTA、Footer）

说明：Figma 文件本身偏品牌探索；本版已结合你提供的官网页面截图补齐页面级规范，可直接用于 CredBridge 的风格改造。

## 2. 视觉 DNA（可迁移到产品 UI 的核心特征）

### 2.1 整体气质

- 关键词：`Future Noir`、`Neo-Organic`、`Luminous Material`
- 主观感受：黑场舞台 + 发光材质 + 流体形变，强调高科技、神秘、安全、沉浸。
- 品牌表达方向：不是扁平 SaaS，而是「有质感的安全计算界面」。

### 2.2 形态语言

- 背景：深色纯净底，叠加低频、柔和、大片的渐变光晕/丝带。
- 主体：有机球体、波纹、液态折射材质（高光+半透明感）。
- 组件轮廓：偏圆角，避免硬直角；阴影和描边都较柔软。

### 2.3 视觉对比策略

- 对比来自「亮度与饱和度」而非粗重描边。
- 在大面积暗色中，用高亮点色做功能引导（CTA、状态、关键数字）。

## 3. 色彩系统（建议作为 CredBridge v1 主题 Token）

以下颜色来自主视觉节点量化提取与参考拼贴风格归纳。

### 3.0 品牌强制标准色（以你最新输入为准）

以下 4 个颜色定义为 Toani/CredBridge 联合视觉改造的**强制品牌色**：

- Brand Primary: `#8AC500`
- Brand Highlight: `#DDFF8E`
- Brand Secondary: `#C0E95F`
- Brand Deep: `#73981D`

建议 token 固化：

- `--brand-primary: #8AC500`
- `--brand-highlight: #DDFF8E`
- `--brand-secondary: #C0E95F`
- `--brand-deep: #73981D`

### 3.1 核心色板（Primary Theme）

- `--bg-0: #0F1208`（主背景，接近黑绿）
- `--bg-1: #1A220F`（次级背景层）
- `--surface-0: #385318`（卡片深色表面）
- `--surface-1: #556424`（卡片悬停/强调表面）
- `--accent-lime-0: #95C739`（主强调）
- `--accent-lime-1: #A8DA5B`（强调高亮）
- `--accent-lime-2: #CCEC6E`（高光边缘）
- `--accent-glow: #E0F49A`（发光/聚焦）
- `--text-primary: #EAF2D7`（主文本）
- `--text-secondary: #A9B692`（次文本）
- `--stroke-soft: rgba(224,244,154,0.22)`（柔和描边）

与品牌强制色的映射关系：

- `--accent-lime-0` 优先对齐到 `--brand-primary`（`#8AC500`）
- `--accent-lime-1` 优先对齐到 `--brand-secondary`（`#C0E95F`）
- `--accent-glow` 优先对齐到 `--brand-highlight`（`#DDFF8E`）
- 深色阴影/渐变过渡优先使用 `--brand-deep`（`#73981D`）参与混色

### 3.2 辅助渐变建议

- Hero 光带：`linear-gradient(120deg, #0F1208 0%, #2B3B16 35%, #7FB82E 70%, #E0F49A 100%)`
- 功能强调：`radial-gradient(circle at 30% 30%, #E0F49A 0%, #95C739 35%, #385318 100%)`

### 3.3 状态色映射（与业务语义对齐）

- Success：沿用绿色系，但亮度低于 CTA（避免喧宾夺主）
- Warning：建议使用偏琥珀 `#DCA84A`，保持材质感
- Error：建议使用深暖红 `#B84747`，避免高饱和纯红破坏整体气质

## 4. 组件级样式规范（CredBridge 可直接执行）

### 4.1 页面背景

- 全局使用深色底 + 低透明度渐变蒙层。
- 避免纯平 `#000`；建议叠加 1-2 层极低透明渐变（3%-10%）。

### 4.2 Card / Panel

- 圆角：`16px`（大卡）/ `12px`（中卡）/ `10px`（小卡）
- 背景：深色半透明层 + 轻微噪点或柔光渐变
- 边框：1px 软描边（`--stroke-soft`）
- 阴影：大半径、低不透明度，避免硬阴影

### 4.3 Button

- Primary：Lime 发光按钮，hover 时增加亮度与外发光半径
- Secondary：深色底 + 亮色描边
- 禁止：高饱和纯蓝默认按钮（会破坏风格一致性）

### 4.4 Input / Form

- 输入框底色比卡片更深一级，减少边界噪声
- Focus 态使用柔和光晕，不使用刺眼实线描边
- 错误态维持低亮度红，文案增强可读性而非强视觉冲击

### 4.5 Data 可视化

- 图表底板与页面底色分层明显
- 关键曲线/柱使用 Lime 主色，辅助数据用低饱和灰绿
- 禁止彩虹配色；保持 1 主色 + 1-2 辅色

## 5. 字体与排版风格建议

说明：当前 Figma 可访问内容以图像参考为主，无法可靠提取完整字体家族；以下为风格级建议。

- 标题：几何感、偏未来气质的无衬线（中粗到粗）
- 正文：高可读无衬线，字重正常，优先可读性
- 数字/指标：建议启用等宽数字（tabular nums）
- 排版节奏：大标题紧凑，正文留白充足，避免密集信息墙

## 6. 动效与反馈规范

- 动效基调：`慢速、柔和、连续`，避免弹跳感过强的微动效
- 页面入场：可用 250-450ms 淡入 + 轻微上移
- 焦点变化：用光晕/亮度过渡，不建议位移过大
- 背景动态：可选超低频流动渐变（不干扰阅读）

## 7. CredBridge 改造落地顺序（建议）

1. 建立 design token：先在前端定义颜色、圆角、阴影、间距、动效 token。
2. 改造全局框架：`App shell / 顶栏 / 侧栏 / 基础背景层` 先统一。
3. 改造高频组件：按钮、输入框、卡片、表格、弹窗。
4. 改造关键页面：登录、凭证列表、凭证详情、审计视图。
5. 最后做品牌强化：LOGO、插画材质、空态与加载动效。

## 8. 风险与边界

- 风险 1：当前源稿偏品牌与视觉探索，不是完整 UI 设计系统。
- 风险 2：若直接高强度使用发光效果，可能影响可访问性与信息识别效率。
- 风险 3：在数据密集型页面，需优先保证对比度与层级清晰度。

建议：下一步补充抓取 3-5 个实际产品页面节点（登录、Dashboard、列表、详情、设置），再输出一版组件级精细规范（含字号、间距、状态矩阵、可访问性对比度）。

## 9. 官网截图补充（页面级设计规范）

## 9.1 页面骨架与节奏

- 页面结构采用「强 Hero + 长滚动叙事」：每个章节独立成块，块间留白明显。
- 深色背景连续铺满，模块通过亮度与边框分层，而非块状背景色分割。
- 建议主容器宽度：`1200-1280px`，左右安全边距桌面端 `32-48px`。
- 章节垂直节奏建议：`120/140/160px` 三档（Hero 后首段建议 140+）。

## 9.2 栅格与布局

- 标准内容区采用 12 栅格。
- 两列叙事区（你第 2 张图）：左 6 栅格文字，右 6 栅格协议卡片组。
- 卡片组内部使用均匀 gap（建议 `16-20px`），保持「低噪声规则感」。
- CTA 区（最后一屏）采用 2 列：左文案+按钮，右代码示例卡。

## 9.3 Typography（从截图反推）

- Hero H1：大号、超粗，建议 `64/72`（桌面）；行高紧凑 `1.05-1.15`。
- 一级 Section Title：建议 `52/60` 或 `48/56`，用于“Agents can think...”级别标题。
- 二级标题：`32/40`，用于卡片组标题或模块大字。
- 正文主文案：`28-32` 字号（截图里主段为中大字重的说明句）。
- 正文说明：`22-24` 字号；注释/辅助文案：`16-18`。
- 色彩策略：标题白+荧光绿混排，高亮关键词（动词/能力词）统一用 accent-lime。

## 9.4 导航（Top Nav）规范

- 导航高度建议：`76-84px`，透明或极低透明底。
- 左侧品牌 + 中间导航 + 右侧 docs/CTA。
- CTA（Get Started）是实心荧光绿胶囊按钮，半径建议 `999px`。
- 一级菜单字重偏中等，hover 仅轻微提亮，不做夸张位移。

## 9.5 Hero 规范

- 背景：流体球体居中偏下，叠加低频绿波纹带。
- 标题采用两行结构：上行价值陈述（白），下行核心承诺（绿）。
- 按钮为主次并列：
  - 主按钮：实心 lime，文字深色
  - 次按钮：白底深字或暗底描边（两者选一，页面内保持一致）
- Hero 文案建议宽度：`720-860px`，避免过长影响聚焦。

## 9.6 卡片系统（来自中后段截图）

### A. 协议小卡（右侧列表卡）

- 外观：暗色面板 + 1px 微绿描边 + 极轻内阴影
- 圆角：`14-16px`
- 内边距：`20-24px`
- 内容：标题 + 副标题两层，副标题颜色低对比

### B. 问题清单卡（01/02/03）

- 结构：左编号（大号绿数字）+ 右标题正文
- 卡片高：约 `180-220px`
- 编号字号建议：`56-72`
- 图标与标题同一视觉行，描述文案置于下一行

### C. 能力产品卡（Vault/Control/Facilitate）

- 结构：左上图标，右上状态 Badge，中部标题+说明，底部链接
- Badge：`Available`/`Coming Soon` 使用低饱和底色胶囊
- 链接色：使用 `accent-lime-0`，hover 提亮为 `accent-lime-1`

### D. 复合说明卡（左文案 + 右 bullets）

- 容器大卡使用更大圆角（`18-20px`）
- 右侧 bullet 行采用独立暗底小条，提升信息分块性
- bullet 点使用亮绿色，维持“合规检查点”语义

## 9.7 数据与信任指标区

- 大标题居中，关键词高亮（如 `scale`）。
- 指标行 3 列等分，中间可用细分隔线提升秩序感。
- 数字建议极高对比（白），标签为低对比灰绿。
- 图标线性风格，笔画细且简洁，不做拟物。

## 9.8 CTA + 代码示例区

- 左侧 CTA 文案 + 双按钮（Primary/Secondary），右侧代码卡模拟终端。
- 代码卡背景应比页面稍亮，形成可读性对比。
- 代码高亮建议：
  - 关键字：灰白
  - 字符串/API 域名：绿色或青绿
  - 注释：低对比灰

## 9.9 Footer 规范

- 深色大底，顶部与正文区用超细分隔线切开。
- 多列信息架构（Products / Resources / Company）列间距充分。
- Logo + 简短品牌说明 + 社媒图标置左。
- Footer 链接默认低对比，hover 小幅提亮。

## 10. 组件状态矩阵（实现时必须覆盖）

- Button：`default / hover / active / focus-visible / disabled / loading`
- Card：`default / hover(可选) / selected(可选)`
- Link：`default / hover / visited(可选)`
- Input：`default / focus / error / disabled`
- Badge：`available / soon / warning / neutral`

建议统一状态过渡时长：

- 颜色/阴影：`180-240ms`
- 大块入场：`300-450ms`

## 11. CredBridge 映射建议（按业务模块）

- 登录页：复用 Toani Hero 语法，保留深色品牌场景 + 精简双按钮。
- 凭证列表：采用暗底卡片列表，左主信息右状态标签，减少表格生硬感。
- 凭证详情：使用复合说明卡样式展示元数据、审计轨迹、授权策略。
- 审计页面：指标区 + 时间线卡片，数字与状态统一绿色强调体系。
- 设置/策略页：复用“问题清单卡”布局，改为策略项与限制项。

## 12. 落地验收标准（Design QA）

- 色彩：页面 80%+ 区域在 dark theme token 内，亮色仅承担引导作用。
- 可读性：正文与背景对比符合 WCAG AA（至少正文等级）。
- 一致性：按钮、圆角、描边、阴影只允许使用 token，不写裸值。
- 节奏：章节间距、标题层级、卡片内边距符合统一尺度系统。
- 品牌性：至少有 1 个材质化背景层，但不影响内容可读性。

## 13. Logo 与图标规范（基于附件 `Union.svg`）

来源文件：`/Users/yvan/Downloads/Union.svg`

### 13.1 基础事实

- 尺寸：`28 x 28`
- ViewBox：`0 0 28 28`
- 形态：单路径闭合图形（聊天气泡 + 星芒几何）
- 当前填充：`white`

### 13.2 使用规则

- 深色背景主场景：Logo 使用 `#DDFF8E` 或 `#FFFFFF`。
- 品牌强调场景（按钮旁、Hero 左上角）：优先 `#8AC500`。
- 禁止渐变填充 Logo 主体（保持识别稳定）。
- 最小显示尺寸：`16px`（小于该尺寸细节损失明显）。
- 推荐导航尺寸：`24px` 或 `28px`。

### 13.3 安全留白

- 安全留白建议不小于 Logo 宽度的 `0.5x`（即 `14px` 对应 28px 图标）。
- Logo 左右不得贴边按钮、文本或分割线。

### 13.4 与字标组合

- 图标 + “Toani/CredBridge”字标横排时，间距建议 `8-12px`。
- 字标颜色优先 `--text-primary`，hover 时可轻微提亮，不改变字重。

### 13.5 前端实现建议

- 以 `currentColor` 驱动 SVG 填充，避免多份彩色资源维护。
- 在 React 组件中暴露 `size` 与 `color` 两个属性，统一接 design token。
