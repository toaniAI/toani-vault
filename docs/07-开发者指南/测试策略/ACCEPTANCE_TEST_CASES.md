## 详细测试用例

### TC-SB-001: 会话创建功能

**所属模块**: 沙箱生命周期管理
**优先级**: P0
**验收标准**: 支持创建带上下文的沙箱会话，返回有效 session_id

**测试步骤**:

1. 调用创建会话 API，传入 valid 参数
2. 验证返回包含 session_id
3. 验证返回状态为 creating 或 ready
4. 验证返回包含 websocket_url 和 websocket_token

**预期结果**:

- session_id 格式正确 (sb_xxx)
- websocket_token 为一次性令牌
- 创建时间戳正确

**验证方式**: 单元测试 + API 测试

---

### TC-SB-002: 会话状态管理

**所属模块**: 沙箱生命周期管理
**优先级**: P0
**验收标准**: 正确维护 creating/ready/executing/paused/closed 状态

**测试步骤**:

1. 创建会话，验证状态为 creating → ready
2. 执行操作，验证状态变为 executing → ready
3. 暂停会话，验证状态变为 paused
4. 恢复会话，验证状态变为 ready
5. 关闭会话，验证状态变为 closed

**预期结果**:

- 状态转换符合状态机定义
- 无效状态转换被拒绝
- 状态变更记录审计日志

**验证方式**: 状态机测试
