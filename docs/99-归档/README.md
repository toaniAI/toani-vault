# 归档目录

本目录用于存放历史文档、临时报告和技术规格，供参考使用。

## 归档分类

### 历史报告
存放项目各阶段的历史报告：
- 产品使用报告
- UI 检查和设计报告
- 阶段完成报告
- 性能报告
- 测试报告
- 检查清单

### 技术规格
存放技术规格文档：
- 实现技术规格
- 架构设计规格
- 接口定义规格

### 代码评审
存放代码评审相关报告：
- 代码评审报告
- 边缘案例评审
- 基础设施评审
- API 层评审
- TEE 核心评审
- Vault 加密评审
- LLM 服务评审
- MCP Server 评审

## 归档规则

### 归档条件
以下情况文档会被移至归档：
1. 临时性报告（如测试报告、阶段报告）
2. 已被新文档替代的旧版本
3. 已完成的设计计划和验收文档
4. 历史技术规格和实现细节

### 归档命名
- 保留原始文件名
- 添加归档日期前缀：`YYYYMMDD-原文件名.md`
- 或在子目录中按类别组织

### 归档保留
- 归档文档永久保留，除非明确不再需要
- 重要历史文档添加元数据说明
- 相关文档建立交叉引用

## 使用指南

### 查找归档文档
1. 确定文档类型（报告/规格/评审）
2. 浏览对应子目录
3. 按文件名或日期查找

### 引用归档文档
引用归档文档时，应注明：
- 文档原始目的
- 归档原因
- 相关新文档（如有）
