# CredBridge 功能特性

## 核心功能特性

### 1. TEE 安全保险库

**状态**: ✅ 已实现

CredBridge 采用 Intel SGX TEE（可信执行环境）技术，在硬件级别保护凭证数据的安全。

**核心特性**:
- **硬件级加密隔离**: 所有敏感操作在 Intel SGX Enclave 内执行
- **四层密钥架构**: L0（硬件根密钥）→ L1（Enclave 主密钥）→ L2（用户保险库密钥）→ L3（凭证加密密钥）
- **AES-256-GCM 加密**: 使用认证加密确保数据完整性和机密性
- **密钥派生**: 基于 HKDF-SHA-256 的密钥派生机制
- **内存安全**: 使用 zeroize 技术确保密钥材料在内存中自动清零

**安全优势**:
- 即使操作系统被攻破，Enclave 内的数据仍然安全
- 密钥层次架构确保单条凭证泄露不会影响其他凭证
- 认证加密防止密文篡改

### 2. 多租户隔离

**状态**: ✅ 已实现

完整的 Schema-per-Tenant 多租户架构，支持 SaaS 部署模式。

**隔离机制**:
- **Schema 隔离**: 每个租户拥有独立的数据库 Schema
- **行级安全（RLS）**: 数据库级别的访问控制
- **租户验证**: 所有查询自动附加租户过滤条件
- **用户 ID 哈希**: 用户标识哈希存储，保护隐私

**管理功能**:
- 租户创建和配置
- 租户资源配额管理
- 跨租户访问审计
- 租户数据导出和迁移

### 3. PASETO Token 认证

**状态**: ✅ 已实现

基于 PASETO v4.local 的安全 Token 认证系统。

**Token 特性**:
- **短期有效期**: 默认 15 分钟，降低泄露风险
- **单次使用**: jti（JWT ID）防止重放攻击
- **对称加密**: 使用共享密钥进行加密和验证
- **自包含**: Token 内包含所有必要的认证信息

**Scope 权限系统**:
| Scope | 权限 | 说明 |
|-------|------|------|
| `credential:read` | 读取凭证元数据 | 可访问 ReadCredential 操作 |
| `credential:decrypt` | 解密密文获取明文 | 可访问 DecryptCredential 操作（隐式包含 read） |
| `credential:write` | 创建/更新凭证 | 可访问 CreateCredential 和 UpdateCredential 操作 |
| `credential:delete` | 删除凭证 | 可访问 DeleteCredential 操作 |
| `token:manage` | 管理 Token | 可访问 ManageToken、RevokeToken、RefreshToken 操作 |
| `audit:read` | 读取审计日志 | 可访问 ReadAudit 操作 |
| `admin` | 所有管理权限 | 可访问所有操作 |

**资源级权限**:
- 受限 Token：只能访问白名单中指定的凭证
- 批量权限检查：高效验证多个资源的访问权限

### 4. 审计日志系统

**状态**: ✅ 已实现

不可篡改的审计追踪系统，记录所有敏感操作。

**审计内容**:
- 凭证创建、更新、删除
- 凭证解密操作
- Token 生成、验证、撤销
- 用户登录和认证
- Sandbox 会话操作
- 管理员操作

**审计特性**:
- **不可篡改**: 审计日志使用加密签名保护
- **完整性**: 记录操作者、时间、IP、操作类型、结果等完整信息
- **可追溯**: 支持按用户、时间、操作类型等多维度查询
- **合规性**: 满足 SOC2、GDPR 等合规要求

**查询功能**:
- 时间范围过滤
- 用户/租户过滤
- 操作类型过滤
- 风险等级过滤
- 导出审计报告

### 5. 远程认证协议

**状态**: ✅ 已实现

基于 SGX DCAP 的远程认证协议，验证 Enclave 身份和完整性。

**认证流程**:
1. **挑战生成**: Verifier 生成随机挑战（带时间戳和随机数）
2. **Quote 生成**: Prover（Enclave）使用挑战生成 SGX Quote
3. **Quote 验证**: Verifier 验证 Quote 的 ECDSA 签名、MRENCLAVE、挑战绑定
4. **安全通道建立**: 认证成功后建立加密通信通道

**安全特性**:
- **防重放攻击**: 每次挑战随机生成，仅使用一次
- **身份绑定**: Quote 中的 REPORT_DATA 绑定挑战和 Enclave 身份
- **新鲜性保证**: 挑战严格时间限制（默认 5 分钟）
- **不可否认**: ECDSA P-256 签名提供强不可否认性
- **测量值白名单**: 只允许特定 Enclave 测量值通过认证

**API 支持**:
- `/api/v1/attestation/quote`: 获取当前 DCAP Quote
- `/api/v1/attestation/verify`: 验证 Quote
- `/api/v1/attestation/report`: 获取认证报告
- `/api/v1/attestation/challenge`: 创建认证挑战

### 6. TEE Sandbox 安全执行

**状态**: ✅ 已实现

"凭证不出 Enclave"的浏览器自动化沙箱，支持 AI Agent 在可信执行环境内完成敏感操作。

**核心组件**:

| 组件 | 功能描述 |
|------|----------|
| **Session** | 会话生命周期管理（创建/运行/暂停/关闭） |
| **Pool** | NsjailSandbox 热实例池（≤100ms 启动） |
| **Nsjail** | nsjail 沙箱封装（Namespaces + cgroups + seccomp） |
| **Credential NS** | 凭证命名空间隔离 |
| **Operation Reviewer** | 操作级 AI 审核 |
| **Prompt Injection Detector** | 提示词注入检测 |
| **Isolated Prompt Builder** | 安全提示词构建 |
| **Screenshot Reviewer** | 截图内容审核 |
| **Export Signer** | 导出数据签名验证 |

**安全隔离**:
- **Namespace 隔离**: PID/Network/Mount/IPC/UTS 隔离
- **seccomp 过滤**: 白名单系统调用（~50 个安全调用）
- **cgroups 限制**: CPU/内存/IO 资源限制
- **凭证隔离**: 每会话独立的凭证命名空间
- **无根运行**: 沙箱内以非特权用户运行

**AI 审核**:
- **操作审核**: 每个浏览器操作经过 LLM 安全审核
- **提示词安全**: 多层注入检测和隔离构建
- **安全导出**: 截图/数据导出前 AI 审核 + 数字签名

**性能指标**:
- 热实例启动：≤ 100ms（本地）/ ≤ 50ms（TEE 硬件）
- 浏览器操作延迟：≤ 2s（本地）/ ≤ 1.5s（TEE 硬件）
- AI 审核延迟：≤ 500ms
- 并发会话数：50（本地）/ 100（TEE 硬件）

### 8. SDK 生态系统

**状态**: ✅ 已实现

提供 TypeScript 和 Rust 两种语言的客户端 SDK。

#### TypeScript SDK

**安装**:
```bash
npm install @credbridge/sdk
# 或
yarn add @credbridge/sdk
```

**核心功能**:
- HTTP 客户端：REST API 调用
- Sandbox API: 浏览器自动化操作
- WebSocket 连接：实时事件监听
- Token 管理：认证和 Token 刷新

**使用示例**:
```typescript
import { CredBridgeSDK, OperationType } from '@credbridge/sdk';

const sdk = new CredBridgeSDK({
  baseUrl: 'https://api.credbridge.io',
  token: 'v4.local.your-paseto-token',
});

// 创建会话
const { sessionId } = await sdk.sandbox.createSession({
  serviceId: 'schwab',
  credentialId: 'cred-123',
  startUrl: 'https://www.schwab.com',
});

// 导航到登录页面
await sdk.sandbox.navigate(sessionId, 'https://www.schwab.com/login');

// 填写凭证并登录
await sdk.sandbox.fill(sessionId, '#username', '{{CREDENTIAL.username}}');
await sdk.sandbox.fill(sessionId, '#password', '{{CREDENTIAL.password}}');
await sdk.sandbox.click(sessionId, '#login-button');
```

#### Rust SDK

**功能**:
- 类型安全的 API 客户端
- 异步支持（Tokio）
- 加密操作支持
- 错误处理

### 10. CLI 命令行工具

**状态**: ✅ 已实现

功能完整的命令行管理工具。

**安装**:
```bash
cargo install --path cli
```

**核心命令**:
```bash
# 认证
credbridge auth login --url https://api.credbridge.io --token <token>

# 凭证管理
credbridge credentials list
credbridge credentials create --name prod-db --type database --value "postgres://..."
credbridge credentials decrypt <credential-id>

# Token 管理
credbridge tokens verify
credbridge tokens revoke

# 配置管理
credbridge config show
credbridge config set output_format json
```
