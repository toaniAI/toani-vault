# CredBridge 项目介绍

## 项目定位

CredBridge 是一个 AI 原生零信任凭证保险库系统，采用 Intel SGX TEE（可信执行环境）技术，实现四层密钥层次架构，确保凭证数据在硬件级别的安全隔离中处理。

作为 TEE 安全保险库，CredBridge 为 AI Agent 提供"凭证不出 Enclave"的安全浏览器自动化能力，支持 AI Agent 在可信执行环境内完成敏感操作。

## 核心能力

### TEE 安全保险库
- Intel SGX TEE 硬件级加密隔离
- 四层密钥层次派生（L0-L3）
- AES-256-GCM 认证加密存储

### 多租户隔离
- Schema-per-Tenant 架构
- 行级安全（RLS）控制
- 租户间数据完全隔离

### PASETO Token 认证
- v4.local 安全 Token
- 15 分钟短期有效期
- jti 单次使用防重放
- 细粒度 Scope 权限系统

### 审计日志系统
- 不可篡改的审计追踪
- 所有凭证操作全记录
- 合规性支持

### 远程认证协议
- SGX DCAP 远程证明
- 挑战 - 响应身份验证
- ECDSA P-256 签名
- 防重放攻击机制

### TEE Sandbox 安全执行
- 浏览器自动化沙箱
- Nsjail 隔离（Namespaces + cgroups + seccomp）
- AI 操作审核引擎
- 提示词注入检测
- 安全导出通道（截图/数据签名）

### Web 控制台
- React 管理界面
- TypeScript 前端
- 实时会话监控

### SDK 生态系统
- TypeScript SDK（HTTP + WebSocket）
- Rust SDK
- 完整的客户端支持

### MCP Server 集成
- Model Context Protocol 支持
- AI Agent 无缝集成
- 标准化接口

## 技术栈

### 后端技术
- **语言**: Rust (Edition 2024)
- **Web 框架**: Axum 0.7
- **异步运行时**: Tokio
- **数据库**: PostgreSQL + SQLx
- **缓存**: Redis
- **密钥管理**: HashiCorp Vault
- **认证**: PASETO v4.local

### 前端技术
- **框架**: React
- **语言**: TypeScript
- **状态管理**: React Hooks
- **UI 组件**: 自定义组件库

### TEE 技术
- **硬件**: Intel SGX
- **驱动**: SGX DCAP
- **密封**: SGX Sealing Key
- **沙箱**: Nsjail + Chromium

### 加密技术
- **密钥派生**: HKDF-SHA-256
- **对称加密**: AES-256-GCM
- **非对称加密**: ECDSA P-256
- **安全内存**: zeroize crate

### 部署技术
- **容器**: Docker
- **编排**: Kubernetes
- **监控**: Prometheus + Grafana
- **日志**: ELK Stack

## 项目目标

1. **零信任安全**: 默认不信任任何内部或外部访问，所有操作需经过验证
2. **AI 原生设计**: 为 AI Agent 提供安全的凭证访问和浏览器自动化能力
3. **硬件级安全**: 利用 Intel SGX TEE 技术实现硬件级别的安全隔离
4. **多租户支持**: 完整的多租户隔离，支持 SaaS 部署模式
5. **易用性**: 提供 SDK、CLI、Web 控制台等多种使用方式

## 适用场景

- **AI Agent 凭证管理**: 为 AI Agent 提供安全的凭证存储和访问
- **浏览器自动化**: 在 TEE 沙箱内执行敏感的浏览器自动化任务
- **金融机构集成**: 安全访问银行、证券等金融服务
- **企业凭证保险库**: 企业级凭证集中管理和审计
- **合规性要求**: 满足严格的数据保护和审计要求
