# CredBridge 快速开始

> **迁移注意**: SDK 包已从 `@credbridge/sdk` 重命名为 `@toani/vault-sdk`，旧包名已弃用。请将 `import { CredBridgeSDK }` 改为 `import { ToaniVaultSDK }`。

本指南将帮助您快速部署和开始使用 CredBridge。

## 环境要求

### 系统要求

**最低配置**:
- **CPU**: Intel Core 6 代或更新（支持 SGX）
- **内存**: 8GB RAM
- **存储**: 20GB 可用空间
- **操作系统**: Linux（Ubuntu 20.04+、CentOS 8+）或 macOS（开发模式）

**推荐配置**:
- **CPU**: Intel Xeon E-系列（支持 SGX2）
- **内存**: 16GB RAM
- **存储**: 50GB SSD
- **操作系统**: Ubuntu 22.04 LTS

### 依赖安装

#### 1. Docker 和 Docker Compose
```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 验证安装
docker --version
docker compose version
```

#### 2. Rust 工具链（仅开发模式）
```bash
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# 验证安装
rustc --version
cargo --version
```

#### 3. Intel SGX 驱动（生产环境）
```bash
# Ubuntu 20.04/22.04
sudo apt install -y libsgx-dcap-default-qpl libsgx-dcap-ql libsgx-dcap-quote-verify

# 验证 SGX 支持
cat /proc/cpuinfo | grep sgx
ls -la /dev/sgx*
```

## 快速部署

### 方式一：Docker 部署（推荐）

#### 1. 克隆项目
```bash
git clone https://github.com/credbridge/credbridge.git
cd credbridge
```

#### 2. 配置环境变量
```bash
# 创建配置文件
cp .env.example .env

# 编辑配置
vim .env
```

**必要配置**:
```bash
# 数据库配置
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/credbridge

# Redis 配置
REDIS_URL=redis://localhost:6379

# Vault 配置（可选）
VAULT_ADDR=http://localhost:8200
VAULT_TOKEN=your_vault_token

# Enclave 配置
ENCLAVE_DEBUG_MODE=true  # 开发模式设为 true
ENCLAVE_SEAL_POLICY=Mrsigner

# JWT 密钥（生产环境请更改）
JWT_SECRET=your-super-secret-key-at-least-32-characters
```

#### 3. 启动服务
```bash
# 使用 Docker Compose 启动所有服务
docker compose up -d

# 查看服务状态
docker compose ps

# 查看日志
docker compose logs -f credbridge
```

#### 4. 运行数据库迁移
```bash
# 进入容器
docker compose exec credbridge bash

# 运行迁移
cargo sqlx migrate run

# 退出容器
exit
```

#### 5. 验证部署
```bash
# 健康检查
curl http://localhost:8080/health

# 预期响应
# {"status":"ok","timestamp":"2026-03-20T10:00:00Z"}
```


#### 3. 构建和运行
```bash

# 运行迁移

# 构建项目

```

### 方式三：Kubernetes 部署（生产）

#### 1. 准备 Kubernetes 集群
```bash
# 确保 kubectl 已配置
kubectl cluster-info

# 创建命名空间
kubectl create namespace credbridge
```

#### 2. 创建 Secrets
```bash

kubectl create secret generic credbridge-secrets \
  --from-literal=database-url='postgresql://...' \
  --from-literal=redis-url='redis://...' \
  --from-literal=jwt-secret='your-secret' \
  -n credbridge
```

#### 3. 部署应用
```bash
# 应用配置
kubectl apply -f k8s/deployment.yaml -n credbridge
kubectl apply -f k8s/service.yaml -n credbridge
kubectl apply -f k8s/ingress.yaml -n credbridge

# 查看部署状态
kubectl get pods -n credbridge
kubectl get svc -n credbridge
```

## 基本使用

### 1. 创建第一个凭证

#### 使用 CLI
```bash
# 安装 CLI
cargo install --path cli

# 登录
credbridge auth login \
  --url http://localhost:8080 \
  --token <your-paseto-token>

# 创建凭证
credbridge credentials create \
  --name my-database \
  --type database \
  --value "postgres://user:password@localhost:5432/mydb"

# 查看凭证列表
credbridge credentials list
```

#### 使用 REST API
```bash
# 创建凭证
curl -X POST http://localhost:8080/api/v1/credentials \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "service_id": "my-database",
    "credential_type": "database",
    "plaintext_data": {
      "username": "admin",
      "password": "secret_password"
    }
  }'

# 响应
{
  "credential_id": "018f1b4e-7e9e-7f3a-8b5c-2d4e6f8a0b2c",
  "service_id": "my-database",
  "credential_type": "database",
  "created_at": "1709990400"
}
```

#### 使用 TypeScript SDK
```typescript
import { ToaniVaultSDK } from '@toani/vault-sdk';

const sdk = new ToaniVaultSDK({
  baseUrl: 'http://localhost:8080',
  token: 'v4.local.your-paseto-token',
});

// 创建凭证
const credential = await sdk.credentials.create({
  serviceId: 'my-database',
  credentialType: 'database',
  plaintextData: {
    username: 'admin',
    password: 'secret_password',
  },
});

console.log('Created credential:', credential.credentialId);
```

#### Sandbox 使用（浏览器自动化）
```typescript
import { ToaniVaultSDK, OperationType } from '@toani/vault-sdk';

const sdk = new ToaniVaultSDK({
  baseUrl: 'http://localhost:8080',
  token: 'v4.local.your-paseto-token',
});

async function automateTask() {
  // 创建会话
  const { sessionId } = await sdk.sandbox.createSession({
    serviceId: 'example',
    credentialId: 'cred-123',
    startUrl: 'https://example.com',
  });

  try {
    // 导航
    await sdk.sandbox.navigate(sessionId, 'https://example.com/login');

    // 填写表单
    await sdk.sandbox.fill(sessionId, '#username', '{{CREDENTIAL.username}}');
    await sdk.sandbox.fill(sessionId, '#password', '{{CREDENTIAL.password}}');

    // 点击按钮
    await sdk.sandbox.click(sessionId, '#login-button');

    // 等待页面加载
    await sdk.sandbox.waitForSelector(sessionId, '.dashboard', {
      timeout: 30000,
    });

    // 获取文本
    const result = await sdk.sandbox.getText(sessionId, '.welcome-message');
    console.log('Welcome message:', result);

  } finally {
    // 关闭会话
    await sdk.sandbox.closeSession(sessionId);
  }
}

automateTask().catch(console.error);
```

## 认证流程

CredBridge 采用 **Privy 钱包优先** 的认证模式，用户通过钱包（MetaMask、WalletConnect 等）进行身份验证。

### 认证流程概览

```text
1. 前端使用 Privy SDK 认证用户，获取 Privy Access Token
2. 前端调用 POST /auth/session，传入 Privy Token
3. 后端验证 Privy Token，创建或获取用户记录
4. 创建 AuthSession，返回 Session Token
5. 后续请求使用 Session Token（通过 Authorization: Bearer 头）
```

### 前端集成（推荐）

使用 Privy React SDK 进行钱包认证：

```typescript
import { PrivyProvider } from '@privy-io/react-auth';

// 1. 配置 Privy
function App() {
  return (
    <PrivyProvider appId="your-privy-app-id">
      <YourApp />
    </PrivyProvider>
  );
}

// 2. 使用认证
import { usePrivy, useWallets } from '@privy-io/react-auth';

function LoginPage() {
  const { login, authenticated, user } = usePrivy();
  const { wallets } = useWallets();

  // 登录
  const handleLogin = async () => {
    await login();
  };

  // 认证成功后创建会话
  useEffect(() => {
    if (authenticated && user) {
      const privyToken = user.accessToken;
      // 调用后端创建会话
      createBackendSession(privyToken);
    }
  }, [authenticated, user]);

  return (
    <button onClick={handleLogin}>
      Connect Wallet
    </button>
  );
}

// 3. 创建后端会话
async function createBackendSession(privyAccessToken: string) {
  const response = await fetch('/api/v1/auth/session', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      privy_access_token: privyAccessToken,
      invitation_token: localStorage.getItem('invitation_token'), // 可选
    }),
  });

  const { session } = await response.json();
  // 存储 Session Token 用于后续请求
  localStorage.setItem('session_token', session.session_token);
}
```

### 后端 API 调用

使用 Session Token 调用受保护的 API：

```bash
# 创建会话（使用 Privy Token）
curl -X POST http://localhost:8080/api/v1/auth/session \
  -H "Content-Type: application/json" \
  -d '{
    "privy_access_token": "<privy_token_from_frontend>"
  }'

# 响应
{
  "user": {
    "id": "uuid",
    "display_name": "User Name",
    "status": "active",
    "identities": [{
      "provider": "wallet",
      "wallet_address": "0x1234...",
      "is_primary": true
    }]
  },
  "session": {
    "id": "uuid",
    "session_token": "v4.local.xxx",
    "expires_at": "2024-03-21T00:00:00Z",
    "mfa_status": "not_required"
  },
  "membership": {
    "tenant_id": "uuid",
    "role": "member",
    "scopes": ["credential:read", "credential:write"]
  }
}

# 获取当前用户信息
curl -X GET http://localhost:8080/api/v1/auth/me \
  -H "Authorization: Bearer <session_token>"

# 注销会话
curl -X POST http://localhost:8080/api/v1/auth/logout \
  -H "Authorization: Bearer <session_token>"
```

```bash
# 消费邀请 Token，创建成员资格

```

### 服务间认证（开发/运维）

对于服务间调用或运维操作，可手动生成 PASETO Token：

```rust
use pasetors::{
    claims::Claims,
    keys::SymmetricKey,
    version4::V4,
};

let key = SymmetricKey::<V4>::from_key_bytes(&[0u8; 32]);
let mut claims = Claims::new().unwrap();
claims.subject("service-account").unwrap();
claims.issued_at(&chrono::Utc::now().to_rfc3339()).unwrap();
claims.expiration(&chrono::Utc::now().add(chrono::Duration::hours(24)).to_rfc3339()).unwrap();

let token = pasetors::local::encrypt(&key, &claims, None, None).unwrap();
println!("Token: {}", token);
```
