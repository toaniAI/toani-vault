# CredBridge 快速开始

本指南将帮助您快速部署和开始使用 CredBridge。

## 环境要求

### 系统要求

**最低配置**:
- **CPU**: Intel Core 6 代或更新（支持 SGX）
- **内存**: 8GB RAM
- **存储**: 20GB 可用空间
- **操作系统**: Linux（Ubuntu 20.04+、CentOS 8+）或 macOS（开发模式）

**推荐配置**:
- **CPU**: Intel Xeon E-系列（支持 SGX2）
- **内存**: 16GB RAM
- **存储**: 50GB SSD
- **操作系统**: Ubuntu 22.04 LTS

### 依赖安装

#### 1. Docker 和 Docker Compose
```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 验证安装
docker --version
docker compose version
```

#### 2. Rust 工具链（仅开发模式）
```bash
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# 验证安装
rustc --version
cargo --version
```

#### 3. Intel SGX 驱动（生产环境）
```bash
# Ubuntu 20.04/22.04
sudo apt install -y libsgx-dcap-default-qpl libsgx-dcap-ql libsgx-dcap-quote-verify

# 验证 SGX 支持
cat /proc/cpuinfo | grep sgx
ls -la /dev/sgx*
```

## 快速部署

### 方式一：Docker 部署（推荐）

#### 1. 克隆项目
```bash
git clone https://github.com/credbridge/credbridge.git
cd credbridge
```

#### 2. 配置环境变量
```bash
# 创建配置文件
cp .env.example .env

# 编辑配置
vim .env
```

**必要配置**:
```bash
# 数据库配置
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/credbridge

# Redis 配置
REDIS_URL=redis://localhost:6379

# Vault 配置（可选）
VAULT_ADDR=http://localhost:8200
VAULT_TOKEN=your_vault_token

# Enclave 配置
ENCLAVE_DEBUG_MODE=true  # 开发模式设为 true
ENCLAVE_SEAL_POLICY=Mrsigner

# JWT 密钥（生产环境请更改）
JWT_SECRET=your-super-secret-key-at-least-32-characters
```

#### 3. 启动服务
```bash
# 使用 Docker Compose 启动所有服务
docker compose up -d

# 查看服务状态
docker compose ps

# 查看日志
docker compose logs -f credbridge
```

#### 4. 运行数据库迁移
```bash
# 进入容器
docker compose exec credbridge bash

# 运行迁移
cargo sqlx migrate run

# 退出容器
exit
```

#### 5. 验证部署
```bash
# 健康检查
curl http://localhost:8080/health

# 预期响应
# {"status":"ok","timestamp":"2026-03-20T10:00:00Z"}
```

### 方式二：源码部署（开发）

#### 1. 安装依赖
```bash
# 安装 PostgreSQL
sudo apt install -y postgresql postgresql-contrib

# 安装 Redis
sudo apt install -y redis-server

# 安装 SQLx CLI
cargo install sqlx-cli
```

#### 2. 创建数据库
```bash
# 创建数据库和用户
sudo -u postgres psql <<EOF
CREATE DATABASE credbridge;
CREATE USER credbridge WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE credbridge TO credbridge;
EOF
```

#### 3. 构建和运行
```bash
# 克隆项目
git clone https://github.com/credbridge/credbridge.git
cd credbridge

# 运行迁移
cargo sqlx migrate run

# 构建项目
cargo build --release

# 运行服务
cargo run --release
```

### 方式三：Kubernetes 部署（生产）

#### 1. 准备 Kubernetes 集群
```bash
# 确保 kubectl 已配置
kubectl cluster-info

# 创建命名空间
kubectl create namespace credbridge
```

#### 2. 创建 Secrets
```bash
# 创建数据库 Secret
kubectl create secret generic credbridge-secrets \
  --from-literal=database-url='postgresql://...' \
  --from-literal=redis-url='redis://...' \
  --from-literal=jwt-secret='your-secret' \
  -n credbridge
```

#### 3. 部署应用
```bash
# 应用配置
kubectl apply -f k8s/deployment.yaml -n credbridge
kubectl apply -f k8s/service.yaml -n credbridge
kubectl apply -f k8s/ingress.yaml -n credbridge

# 查看部署状态
kubectl get pods -n credbridge
kubectl get svc -n credbridge
```

## 基本使用

### 1. 创建第一个凭证

#### 使用 CLI
```bash
# 安装 CLI
cargo install --path cli

# 登录
credbridge auth login \
  --url http://localhost:8080 \
  --token <your-paseto-token>

# 创建凭证
credbridge credentials create \
  --name my-database \
  --type database \
  --value "postgres://user:password@localhost:5432/mydb"

# 查看凭证列表
credbridge credentials list
```

#### 使用 REST API
```bash
# 创建凭证
curl -X POST http://localhost:8080/api/v1/credentials \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "service_id": "my-database",
    "credential_type": "database",
    "plaintext_data": {
      "username": "admin",
      "password": "secret_password"
    }
  }'

# 响应
{
  "credential_id": "018f1b4e-7e9e-7f3a-8b5c-2d4e6f8a0b2c",
  "service_id": "my-database",
  "credential_type": "database",
  "created_at": "1709990400"
}
```

#### 使用 TypeScript SDK
```typescript
import { CredBridgeSDK } from '@credbridge/sdk';

const sdk = new CredBridgeSDK({
  baseUrl: 'http://localhost:8080',
  token: 'v4.local.your-paseto-token',
});

// 创建凭证
const credential = await sdk.credentials.create({
  serviceId: 'my-database',
  credentialType: 'database',
  plaintextData: {
    username: 'admin',
    password: 'secret_password',
  },
});

console.log('Created credential:', credential.credentialId);
```

### 2. 使用 SDK 连接

#### TypeScript SDK 安装
```bash
npm install @credbridge/sdk
# 或
yarn add @credbridge/sdk
```

#### 基本使用
```typescript
import { CredBridgeSDK } from '@credbridge/sdk';

const sdk = new CredBridgeSDK({
  baseUrl: 'http://localhost:8080',
  token: 'v4.local.your-paseto-token',
});

// 获取凭证列表
const credentials = await sdk.credentials.list();
console.log('Credentials:', credentials);

// 解密凭证
const decrypted = await sdk.credentials.decrypt('credential-id');
console.log('Decrypted:', decrypted);
```

#### Sandbox 使用（浏览器自动化）
```typescript
import { CredBridgeSDK, OperationType } from '@credbridge/sdk';

const sdk = new CredBridgeSDK({
  baseUrl: 'http://localhost:8080',
  token: 'v4.local.your-paseto-token',
});

async function automateTask() {
  // 创建会话
  const { sessionId } = await sdk.sandbox.createSession({
    serviceId: 'example',
    credentialId: 'cred-123',
    startUrl: 'https://example.com',
  });

  try {
    // 导航
    await sdk.sandbox.navigate(sessionId, 'https://example.com/login');

    // 填写表单
    await sdk.sandbox.fill(sessionId, '#username', '{{CREDENTIAL.username}}');
    await sdk.sandbox.fill(sessionId, '#password', '{{CREDENTIAL.password}}');

    // 点击按钮
    await sdk.sandbox.click(sessionId, '#login-button');

    // 等待页面加载
    await sdk.sandbox.waitForSelector(sessionId, '.dashboard', {
      timeout: 30000,
    });

    // 获取文本
    const result = await sdk.sandbox.getText(sessionId, '.welcome-message');
    console.log('Welcome message:', result);

  } finally {
    // 关闭会话
    await sdk.sandbox.closeSession(sessionId);
  }
}

automateTask().catch(console.error);
```

## 获取 Token

### 方式一：通过 API
```bash
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "your-password"
  }'

# 响应
{
  "token": "v4.local.eyJleHAiOiIyMDI2LTAzLTIwVDEyOjAwOjAwWiIsImp0aSI6Ii4uLiJ9...",
  "expires_in": 900,
  "token_type": "Bearer"
}
```

### 方式二：使用 CLI
```bash
credbridge auth login \
  --url http://localhost:8080 \
  --username admin \
  --password your-password
```

### 方式三：手动生成（开发）
```rust
use pasetors::{
    claims::Claims,
    keys::SymmetricKey,
    version4::V4,
};

let key = SymmetricKey::<V4>::from_key_bytes(&[0u8; 32]);
let mut claims = Claims::new().unwrap();
claims.subject("admin").unwrap();
claims.issued_at(&chrono::Utc::now().to_rfc3339()).unwrap();
claims.expiration(&chrono::Utc::now().add(chrono::Duration::hours(24)).to_rfc3339()).unwrap();

let token = pasetors::local::encrypt(&key, &claims, None, None).unwrap();
println!("Token: {}", token);
```
