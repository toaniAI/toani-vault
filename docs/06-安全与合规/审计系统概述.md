## 系统架构

### 审计系统设计原则

```
┌─────────────────────────────────────────────────────────────────┐
│                    CredBridge 审计系统架构                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  业务服务层                                                      │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │凭证服务  │  │Token 服务 │  │审计服务  │  │Sandbox   │       │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘       │
│       │             │             │             │              │
│       └─────────────┴─────────────┴─────────────┘              │
│                              │                                  │
│  ┌───────────────────────────▼───────────────────────────────┐  │
│  │                   AuditRecorder                            │  │
│  │  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐    │  │
│  │  │事件生成      │  │数字签名      │  │Merkle Tree   │    │  │
│  │  │(Event Gen)   │  │(Ed25519)     │  │(Hash Chain)  │    │  │
│  │  └──────────────┘  └──────────────┘  └──────────────┘    │  │
│  └───────────────────────────┬───────────────────────────────┘  │
│                              │                                  │
│  ┌───────────────────────────▼───────────────────────────────┐  │
│  │                   存储层                                   │  │
│  │  ┌──────────────┐  ┌──────────────┐                      │  │
│  │  │内存存储      │  │immudb 存储   │                      │  │
│  │  │(开发/测试)   │  │(生产环境)    │                      │  │
│  │  └──────────────┘  └──────────────┘                      │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 核心特性

| 特性 | 实现 | 说明 |
|------|------|------|
| **不可篡改** | Merkle Tree + Ed25519 | 数字签名 + 链式哈希 |
| **PII 脱敏** | 自动脱敏引擎 | SSN、密码、API Key 等 |
| **UUID v7** | 时间排序 ID | 更好的数据库性能 |
| **链式结构** | 前向哈希链接 | 每个条目包含前一个条目的哈希 |
| **实时签名** | Ed25519 数字签名 | 每个条目独立签名 |
| **Merkle Tree** | 根哈希聚合 | 快速验证完整性 |

### 审计流程

```
1. 业务操作发生
        ↓
2. 生成审计事件（AuditEntry）
        ↓
3. PII 自动脱敏（PiiRedactor）
        ↓
4. 计算内容哈希（SHA-256）
        ↓
5. 链接前一个条目的哈希
        ↓
6. Ed25519 数字签名
        ↓
7. 更新 Merkle Tree 根哈希
        ↓
8. 存储到后端（内存/immudb）
        ↓
9. 返回签名后的条目（SignedAuditEntry）
```

## 审计事件格式

### AuditEntry 结构

```rust
pub struct AuditEntry {
    /// 事件 ID（UUID v7，时间排序）
    pub id: String,
    
    /// 用户 ID 哈希（SHA-256）
    pub user_id_hash: String,
    
    /// UTC 时间戳（毫秒）
    pub timestamp: u64,
    
    /// 会话标识
    pub session_id: String,
    
    /// 服务名称
    pub service: String,
    
    /// 操作类型
    pub action: AuditAction,
    
    /// 风险等级
    pub risk_tier: RiskTier,
    
    /// 操作结果
    pub outcome: Outcome,
    
    /// TEE MRENCLAVE 测量值
    pub tee_mrenclave: String,
    
    /// Action Token JTI
    pub action_token_jti: String,
    
    /// 脱敏后的参数（可选）
    pub params: Option<Vec<(String, RedactedParam)>>,
    
    /// 错误信息（可选）
    pub error_message: Option<String>,
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | String | ✅ | UUID v7，时间排序 |
| `user_id_hash` | String | ✅ | SHA-256 哈希的用户 ID |
| `timestamp` | u64 | ✅ | UTC 毫秒时间戳 |
| `session_id` | String | ✅ | 会话标识符 |
| `service` | String | ✅ | 服务名称（如 vault-service） |
| `action` | AuditAction | ✅ | 操作类型枚举 |
| `risk_tier` | RiskTier | ✅ | 风险等级 |
| `outcome` | Outcome | ✅ | 操作结果 |
| `tee_mrenclave` | String | ✅ | TEE 测量值 |
| `action_token_jti` | String | ✅ | Action Token 唯一标识 |
| `params` | Option | ❌ | 脱敏参数 |
| `error_message` | Option | ❌ | 错误信息 |

### 操作类型（AuditAction）

```rust
pub enum AuditAction {
    // 凭证操作
    CredentialDecrypt,    // 凭证解密（高风险）
    CredentialAccess,     // 凭证访问（元数据读取）
    CredentialCreate,     // 凭证创建
    CredentialUpdate,     // 凭证更新
    CredentialDelete,     // 凭证删除（高风险）
    
    // Token 操作
    TokenIssue,          // Token 签发
    TokenValidate,       // Token 验证
    TokenRevoke,         // Token 撤销
    TokenRefresh,        // Token 刷新
    
    // 审计操作
    AuditQuery,          // 审计日志查询（高风险）
    AuditExport,         // 审计日志导出
    
    // 密钥操作
    KeyRotation,         // 密钥轮换（极高风险）
    
    // 管理员操作
    AdminLogin,          // 管理员登录（极高风险）
    AdminLogout,         // 管理员登出
    
    // Sandbox 操作
    SandboxCreate,       // 创建沙箱会话
    SandboxExecute,      // 执行沙箱操作
    SandboxExport,       // 沙箱数据导出
}
```

### 风险等级（RiskTier）

```rust
pub enum RiskTier {
    Low,       // 低风险：Token 验证、元数据查询
    Medium,    // 中风险：凭证创建、Token 签发
    High,      // 高风险：凭证解密、审计查询
    Critical,  // 极高风险：密钥轮换、管理员登录
}
```

### 操作结果（Outcome）

```rust
pub enum Outcome {
    Success,     // 操作成功
    Failure,     // 操作失败
    Denied,      // 权限拒绝
    Timeout,     // 操作超时
    Aborted,     // 操作中止
}
```

## 审计事件管理

### 事件生成

```rust
use vault_service::audit::{AuditEntry, AuditAction, Outcome};

// 业务代码中记录审计事件
fn decrypt_credential(
    user_id: &str,
    credential_id: &str,
    session_id: &str,
) -> Result<Plaintext, Error> {
    // ... 执行解密操作 ...
    
    // 记录审计事件
    let entry = AuditEntry::new(
        hash_user_id(user_id),
        session_id,
        "vault-service",
        AuditAction::CredentialDecrypt,
        Outcome::Success,
        get_mrenclave(),
        get_token_jti(),
    )
    .with_param("credential_id", PiiRedactor::plain(credential_id));
    
    // 记录到审计存储
    audit_recorder.record(entry)?;
    
    Ok(plaintext)
}
```

### PII 自动脱敏

```rust
use vault_service::audit::PiiRedactor;

// 自动根据参数名脱敏
let ssn = PiiRedactor::auto_redact("user_ssn", "123-45-6789");
assert_eq!(ssn.to_string(), "[SSN_REDACTED]");

let password = PiiRedactor::auto_redact("password", "secret123");
assert_eq!(password.to_string(), "[PASSWORD_REDACTED]");

let api_key = PiiRedactor::auto_redact("api_key", "sk-123456");
assert_eq!(api_key.to_string(), "[API_KEY_REDACTED]");

// 显式脱敏
let ssn = PiiRedactor::redact_ssn("123-45-6789");
let password = PiiRedactor::redact_password("secret123");
let credit_card = PiiRedactor::redact_credit_card("4111111111111111");

// 不脱敏（普通数据）
let normal = PiiRedactor::plain("visible_value");
assert_eq!(normal.to_string(), "visible_value");
```

### 脱敏规则

| 参数名包含 | 脱敏类型 | 显示值 |
|-----------|---------|--------|
| `password`, `passwd`, `pwd` | PASSWORD | `[PASSWORD_REDACTED]` |
| `ssn`, `social_security` | SSN | `[SSN_REDACTED]` |
| `credit_card`, `cc_number` | CREDIT_CARD | `[CREDIT_CARD_REDACTED]` |
| `api_key`, `apikey`, `secret` | API_KEY | `[API_KEY_REDACTED]` |
| `token`, `bearer` | TOKEN | `[TOKEN_REDACTED]` |
| `email` | EMAIL | `[EMAIL_REDACTED]` |
| `phone`, `mobile` | PHONE | `[PHONE_REDACTED]` |

## 不可篡改存储

### Merkle Tree 结构

```
┌─────────────────────────────────────────────────────────────────┐
│                    Merkle Tree 结构                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  审计条目          叶子节点           中间节点        根节点      │
│                                                                 │
│  Entry 0 ──► Hash(E0) ──┐                                      │
│                         ├────► Hash(H0+H1) ──┐                 │
│  Entry 1 ──► Hash(E1) ──┘                   │                 │
│                                             ├────► Root Hash   │
│  Entry 2 ──► Hash(E2) ──┐                   │                 │
│                         ├────► Hash(H2+H3) ──┘                 │
│  Entry 3 ──► Hash(E3) ──┘                                      │
│                                                                 │
│  每个条目包含：                                                  │
│  - content_hash: 自身内容哈希                                   │
│  - prev_hash: 前一个条目的哈希（链式结构）                       │
│  - merkle_root: 截至当前条目的 Merkle 根哈希                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 链式哈希

```rust
use vault_service::audit::AuditLogChain;

let mut chain = AuditLogChain::new();

// 第一个条目
let entry1 = AuditEntry::new(/* ... */);
let signed1 = chain.record(entry1)?;
// signed1.prev_hash = genesis_hash
// signed1.merkle_root = hash(entry1)

// 第二个条目
let entry2 = AuditEntry::new(/* ... */);
let signed2 = chain.record(entry2)?;
// signed2.prev_hash = signed1.content_hash
// signed2.merkle_root = hash(signed1.merkle_root + entry2)

// 验证链完整性
let is_valid = chain.verify()?;
assert!(is_valid);
```

### 数字签名

```rust
use vault_service::audit::{SigningKeyPair, AuditRecorder};

// 生成 Ed25519 密钥对
let key_pair = SigningKeyPair::generate()?;

// 创建记录器
let recorder = AuditRecorder::new(key_pair, 10000)?;

// 记录并签名
let entry = AuditEntry::new(/* ... */);
let signed_entry = recorder.record(entry)?;

// 验证签名
let is_valid = recorder.verify_signature(&signed_entry)?;
assert!(is_valid);
```

### 完整性验证

```rust
use vault_service::audit::AuditStorage;

let storage = create_memory_storage()?;

// 记录一系列事件
for i in 0..10 {
    let entry = AuditEntry::new(/* ... */);
    storage.record(entry)?;
}

// 验证整个链的完整性
let is_valid = storage.verify()?;
assert!(is_valid, "审计链应该有效");

// 验证单个条目
let result = storage.verify_entry(5)?;
assert!(result.verified);
assert!(result.signature_valid);
assert!(result.chain_hash_valid);
assert!(result.merkle_proof_valid);
```

### 防篡改机制

```rust
use vault_service::audit::{create_memory_storage, AuditEntry, AuditAction};

let storage = create_memory_storage()?;

// 记录一系列事件
for i in 0..5 {
    let entry = AuditEntry::new(
        format!("user_{}", i),
        "session",
        "service",
        AuditAction::TokenValidate,
        Outcome::Success,
        "mrenclave",
        format!("jti_{}", i),
    );
    storage.record(entry).unwrap();
}

// 验证初始状态
let is_valid = storage.verify().expect("Should verify");
assert!(is_valid, "Chain should be valid initially");

// 尝试篡改中间条目
// （实际生产中无法做到，因为已签名并存储到 immudb）
let tampered = storage.get_entry(2).unwrap();
// 如果篡改 content_hash，验证会失败

// 链式验证会检测到篡改
let entries = storage.query_recent(5).expect("Should query");
for i in 1..entries.len() {
    // 当前条目的 prev_hash 应该等于前一个条目的 content_hash
    assert_eq!(
        entries[i].prev_hash,
        entries[i - 1].content_hash,
        "Chain link {} should reference previous entry",
        i
    );
}
```

## 合规检查

### 审计报告

```rust
use vault_service::audit::AuditRecorder;

let recorder = AuditRecorder::new(key_pair, 10000)?;

// 生成审计报告
let report = recorder.generate_report(
    Some(start_time),  // 开始时间
    Some(end_time)     // 结束时间
)?;

println!("总条目数：{}", report.total_entries);
println!("成功：{}", report.success_count);
println!("失败：{}", report.failure_count);
println!("高风险操作：{}", report.high_risk_count);
println!("Merkle 根：{}", report.merkle_root);
```

### 报告结构

```rust
pub struct AuditReport {
    /// 总条目数
    pub total_entries: usize,
    
    /// 成功数
    pub success_count: usize,
    
    /// 失败数
    pub failure_count: usize,
    
    /// 高风险操作数
    pub high_risk_count: usize,
    
    /// Merkle Tree 根哈希
    pub merkle_root: String,
    
    /// 开始时间
    pub start_time: Option<u64>,
    
    /// 结束时间
    pub end_time: Option<u64>,
}
```

### 合规检查清单

| 检查项 | 要求 | 实现 |
|--------|------|------|
| **日志完整性** | 审计日志不可篡改 | Merkle Tree + Ed25519 签名 |
| **PII 保护** | 敏感数据脱敏 | 自动 PII 脱敏引擎 |
| **时间同步** | 所有日志使用 UTC | UTC 毫秒时间戳 |
| **操作追溯** | 可追溯到具体用户 | user_id_hash + session_id |
| **权限分离** | 不同角色不同权限 | Scope 权限系统 |
| **保留期限** | 审计日志保留至少 1 年 | immudb 持久化存储 |
| **查询审计** | 审计查询本身也要记录 | AuditQuery 操作 |
| **导出验证** | 导出日志可验证 | 导出签名 + Merkle Proof |

### SOC2 合规性

CredBridge 审计系统满足 SOC2 Type II 要求：

- **CC6.1**: 逻辑访问控制 - 通过 Scope 权限系统实现
- **CC6.6**: 审计日志 - 不可篡改的审计追踪
- **CC7.2**: 系统监控 - 实时审计事件记录
- **CC7.3**: 异常检测 - 高风险操作标记

### GDPR 合规性

- **第 5 条**: 数据最小化 - PII 自动脱敏
- **第 25 条**: 设计隐私保护 - 用户 ID 哈希存储
- **第 30 条**: 处理记录 - 完整审计追踪
- **第 32 条**: 安全处理 - 加密和签名
