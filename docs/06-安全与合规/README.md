## 安全特性总览

| 特性             | 实现                    | 安全等级    |
| ---------------- | ----------------------- | ----------- |
| **TEE 硬件隔离** | Intel SGX Enclave       | 🔴 Critical |
| **四层密钥架构** | L0-L3 密钥派生          | 🔴 Critical |
| **远程认证**     | SGX DCAP Quote 验证     | 🔴 Critical |
| **沙箱隔离**     | nsjail + Namespaces     | 🔴 Critical |
| **审计日志**     | Merkle Tree + Ed25519   | 🟠 High     |
| **凭证加密**     | AES-256-GCM             | 🟠 High     |
| **Token 认证**   | PASETO v4.local         | 🟠 High     |
| **多租户隔离**   | Schema-per-Tenant + RLS | 🟠 High     |
