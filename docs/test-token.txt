## 使用方法

### CLI 配置
```bash
credbridge config init --url http://localhost:8080 --token "<token>"
```

### curl 测试
```bash
curl -H "Authorization: Bearer <token>" http://localhost:8080/api/v1/credentials
```

## API 端点

- 健康检查：`GET http://localhost:8080/health`
- 凭证列表：`GET http://localhost:8080/api/v1/credentials`
- 创建凭证：`POST http://localhost:8080/api/v1/credentials`
- 沙箱会话：`POST http://localhost:8080/sandbox/sessions`
