## 1. API 验收

### 1.1 端点完整性

- [ ] **POST /sandbox/sessions** - 创建沙箱会话
  - 请求验证通过
  - 响应格式正确
  - 会话成功创建

- [ ] **GET /sandbox/sessions** - 列出所有会话
  - 分页功能正常
  - 过滤功能正常
  - 响应包含完整会话列表

- [ ] **GET /sandbox/sessions/{id}** - 获取会话详情
  - 正确返回会话信息
  - 包含状态、创建时间、过期时间
  - 404 处理正确

- [ ] **DELETE /sandbox/sessions/{id}** - 关闭会话
  - 会话正确关闭
  - 资源释放成功
  - 无法操作已关闭会话

- [ ] **POST /sandbox/sessions/{id}/execute** - 执行操作
  - 支持所有操作类型 (navigate, click, fill, get_text, screenshot, export, execute_script, wait, custom)
  - 操作执行成功
  - 错误处理正确

- [ ] **POST /sandbox/sessions/{id}/pause** - 暂停会话
  - 会话状态变为 paused
  - 无法执行新操作
  - 恢复功能正常

- [ ] **POST /sandbox/sessions/{id}/resume** - 恢复会话
  - 会话状态恢复为 ready
  - 可继续执行操作

- [ ] **POST /sandbox/sessions/{id}/screenshot** - 截图导出
  - 支持 PNG/JPEG 格式
  - 支持全页面/元素截图
  - Base64 编码正确

- [ ] **POST /sandbox/sessions/{id}/export** - 数据导出
  - 支持 JSON/CSV/HTML 格式
  - 数据提取规则工作正常
  - 导出数据完整

- [ ] **WS /sandbox/sessions/{id}/stream** - WebSocket 实时流
  - 连接建立成功
  - 双向通信正常
  - 心跳机制有效

### 1.2 认证和授权

- [ ] **PASETO Token 认证**
  - Token 解析正确
  - 过期 Token 被拒绝
  - 无效 Token 返回 401

- [ ] **Scope 权限控制**
  - `sandbox:read` 可读取会话信息
  - `sandbox:write` 可创建和控制会话
  - 权限不足返回 403

### 1.3 错误处理

- [ ] **统一响应格式**
  - 成功响应包含 `success: true`
  - 错误响应包含 `success: false`
  - 包含 `error` 和 `message` 字段
  - 包含 `meta` 元数据

- [ ] **HTTP 状态码**
  - 200/201 成功
  - 400 请求参数错误
  - 401 未授权
  - 403 禁止访问
  - 404 资源不存在
  - 409 状态冲突
  - 429 速率限制
  - 500/503 服务器错误

### 1.4 响应格式

- [ ] **JSON 格式统一**
  - 所有响应为有效 JSON
  - 字符编码 UTF-8
  - Content-Type: application/json
