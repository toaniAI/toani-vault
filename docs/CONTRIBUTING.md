# CredBridge 文档维护规范

本文档定义 CredBridge 项目的文档编写、组织和维护标准。

## 文档分类体系

### 核心文档分类

1. **01-项目概述** - 项目介绍、功能特性、架构设计、快速开始
2. **02-核心功能模块** - 各功能模块详细文档
3. **03-API 参考** - REST API、SDK API 等接口文档
4. **04-SDK 与工具** - SDK 使用指南、工具文档
5. **05-部署与运维** - 部署指南、监控、运维手册
6. **06-安全与合规** - 安全架构、合规文档
7. **07-开发者指南** - 开发环境、测试、贡献指南
8. **08-用户指南** - 用户手册、使用指南
9. **09-故障排除** - 常见问题、故障排查
10. **99-归档** - 历史文档、临时报告、技术规格

### 文档编号规则

- 使用数字前缀表示分类：`01-`, `02-`, `03-`...
- 分类内文档不再编号
- 子目录使用有意义的名称

## 文档编写规范

### 文件命名

✅ **推荐**:
- `api-reference.md` - 英文文件名（技术文档）
- `快速开始.md` - 中文文件名（用户文档）
- `SDK-GUIDE.md` - 缩写保持大写
- `deployment.md` - 使用短横线分隔

❌ **避免**:
- `api reference.md` - 包含空格
- `APIReference.md` - 驼峰命名
- `api_reference.md` - 下划线分隔
- `快速开始 V2.md` - 版本号在文件名中

### 文档结构

每个文档应包含：

```markdown
# 文档标题

简要介绍文档内容和目的。

## 章节标题

内容...

### 子标题

详细内容...

## 总结

可选的总结部分。

---

**更新时间**: YYYY-MM-DD
**作者**: 作者名
**状态**: 草稿 | 审核中 | 已发布 | 已归档
```

### 元数据规范

文档顶部可添加元数据：

```yaml
---
title: 文档标题
description: 一句话描述
category: 分类名称
tags:
  - 标签 1
  - 标签 2
created: 2026-03-20
updated: 2026-03-20

---
```

## 文档更新流程

### 新增文档

1. **确定分类**: 选择合适的分类目录
2. **创建文档**: 按照编写规范创建
3. **更新索引**: 在对应 README.md 添加链接
4. **通知团队**: 在团队频道告知新文档

### 更新文档

1. **检查版本**: 确认更新的是最新版
2. **修改内容**: 直接编辑或创建新版本
3. **更新时间戳**: 更新 `updated` 字段
4. **记录变更**: 在文档末尾添加变更记录

### 替换文档

1. **保留原文档**: 移动到新位置或添加版本后缀
2. **创建新文档**: 编写新内容
3. **添加说明**: 在原文档顶部添加指向新文档的链接
4. **更新索引**: 确保所有引用指向新文档

### 归档文档

1. **评估价值**: 确认文档是否有保留价值
2. **移至归档**: 移动到 `99-归档/`对应目录
3. **更新状态**: 在文档顶部添加【已归档】标识
4. **记录原因**: 说明归档原因和相关新文档

## 文档质量控制

### 内容审查

- **准确性**: 技术细节准确无误
- **完整性**: 覆盖所有必要内容
- **一致性**: 术语、风格保持一致
- **可读性**: 结构清晰，易于理解

### 审查清单

在文档发布前检查：

- [ ] 标题准确反映内容
- [ ] 结构清晰，层次分明
- [ ] 代码示例可运行
- [ ] 链接有效
- [ ] 拼写和语法正确
- [ ] 格式符合规范
- [ ] 元数据完整
- [ ] 已添加到索引

### 定期审查

- **核心文档**: 每季度审查一次
- **API 文档**: 每次 API 变更后更新
- **用户指南**: 每半年审查一次
- **归档文档**: 每年清理一次

## 文档版本控制

### 版本命名

使用语义化版本：

- `v1.0.0` - 初始版本
- `v1.1.0` - 新增内容
- `v1.0.1` - 小幅修正

### 版本记录

在文档末尾添加变更历史：

```markdown
## 变更历史

| 版本 | 日期 | 作者 | 变更说明 |
|------|------|------|----------|
| v1.0 | 2026-03-20 |张三 | 初始版本 |
| v1.1 | 2026-03-25 | 李四 | 新增 API 示例 |
```

### 多版本文档

对于需要保留多个版本的文档：

```
docs/
├── api-v1.md
├── api-v2.md
└── api.md -> 指向最新版
```
