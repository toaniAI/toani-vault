# CredBridge Web 前端 - 产品简报

---

## 1. Vision

为 CredBridge TEE 凭证保险库系统提供一个专业、安全、易用的 Web 管理界面，让用户能够像使用 1Password 一样直观地管理敏感凭证，同时保持企业级安全标准。

**愿景陈述**: 成为 AI 时代最安全、最优雅的凭证管理 Web 界面。

---

## 2. 目标用户

### 2.1 主要用户群体

| 用户角色 | 描述 | 核心需求 |
|---------|------|---------|
| **系统管理员** | DevOps/SRE 团队 | 租户配置、用户管理、审计监控 |
| **安全管理员** | 企业安全团队 | 密钥轮换、访问控制、合规审计 |
| **开发人员** | 应用开发者 | API Token 管理、凭证查看、集成调试 |
| **终端用户** | 普通员工 | 个人凭证管理、快速查找、安全共享 |

### 2.2 用户画像

**典型用户: Alex (DevOps 工程师)**
- 需要管理数十个服务的 API 凭证
- 关注操作效率和安全性
- 熟悉命令行但也需要可视化界面
- 需要快速查看访问日志和审计记录

---

## 3. 问题陈述

### 3.1 当前痛点

1. **纯 API/CLI 交互**: 现有系统只有后端 API，非技术用户难以上手
2. **缺乏可视化**: 无法直观查看凭证结构、访问模式、安全状态
3. **审计困难**: 查看审计日志需要直接查询数据库或调用 API
4. **管理复杂**: Token 管理、权限配置缺乏统一界面

### 3.2 机会点

- 提供类似 1Password 的专业凭证管理体验
- 结合 TEE 安全特性，打造差异化安全感知
- 支持多租户管理的 SaaS 化界面

---

## 4. 解决方案概述

### 4.1 产品定位

CredBridge Web Console 是一个面向 CredBridge TEE 凭证保险库的 Web 管理界面，提供：

- **安全凭证管理**: 创建、编辑、删除、查看凭证
- **访问控制**: Token 生成、权限配置、撤销管理
- **审计追溯**: 完整的操作日志和访问历史
- **租户管理**: 多租户配置、配额管理、设置
- **安全态势**: 安全评分、风险提醒、合规报告

### 4.2 核心差异化

1. **TEE 安全可视化**: 展示 Enclave 状态、认证信息、密钥层次
2. **零信任设计**: 每个操作都可审计，每次访问都有记录
3. **AI 原生**: 支持 AI Agent 凭证管理场景

## 5. MVP 范围

### 5.1 必须实现 (MVP)

#### 功能模块
- [x] **用户认证**: 登录、登出、MFA、会话管理
- [x] **凭证管理**: 列表、创建、编辑、删除、查看详情
- [x] **Token 管理**: 生成、查看、撤销 API Token
- [x] **审计日志**: 查看、过滤操作日志
- [x] **租户设置**: 基本配置、用户管理

#### 基础体验
- [x] 深色/浅色主题切换
- [x] 响应式设计（桌面优先）
- [x] 基础权限控制（RBAC）
- [x] 错误处理和加载状态

### 5.2 第二阶段 (V1.1)

- [ ] 凭证分类和标签
- [ ] 高级搜索和过滤
- [ ] 批量操作
- [ ] 审计日志导出

- [ ] 访问请求工作流
