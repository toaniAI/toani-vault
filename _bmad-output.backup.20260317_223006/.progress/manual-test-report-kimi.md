1. **实现登录 API**
   - 添加 `/api/v1/auth/login` 端点
   - 支持用户名/密码验证

2. **完成凭证管理功能**
   - 实现前端凭证列表页面
   - 实现创建/编辑/删除凭证表单
   - 对接后端 API

3. **添加导航侧边栏**
   - 实现响应式侧边栏
   - 包含所有功能模块入口
