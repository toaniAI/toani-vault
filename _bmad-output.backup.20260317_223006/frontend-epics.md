### Story 2.1: 实现登录页面

**故事描述**: 作为用户，我想要通过用户名和密码登录系统，以便访问我的凭证

**验收标准**:

- [ ] 密码显示/隐藏切换
- [ ] 集成后端登录 API
- [ ] 登录成功保存 Token
- [ ] 登录失败显示错误提示

**技术要点**:
```typescript
// 登录表单验证
const loginSchema = z.object({
  username: z.string().min(1, '用户名不能为空'),
  password: z.string().min(1, '密码不能为空'),
});

// 登录 API
POST /auth/login
```

**估算**: 6h

### Story 2.2: 实现路由守卫和权限控制

**故事描述**: 作为系统，我需要保护路由，确保只有认证用户可以访问受保护页面

**验收标准**:
- [ ] 创建 ProtectedRoute 组件
- [ ] 未登录用户重定向到登录页
- [ ] 已登录用户访问登录页重定向到首页
- [ ] 处理 Token 过期
- [ ] 创建 useAuth hook
- [ ] 全局认证状态管理

**技术要点**:
```typescript
// ProtectedRoute 组件
function ProtectedRoute({ children }: { children: React.ReactNode }) {
  const { isAuthenticated, isLoading } = useAuth();

  if (isLoading) return <Loading />;
  if (!isAuthenticated) return <Navigate to="/login" />;

  return children;
}
```

**估算**: 4h
