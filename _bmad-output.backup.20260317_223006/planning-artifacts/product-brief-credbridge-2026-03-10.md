## Vision（产品愿景）

### Executive Summary
CredBridge 是首个专为 AI Agent 设计的零信任凭证保险库系统，采用商用级安全标准（对标 1Password），让 AI 能够安全地代表用户行动——无需暴露用户秘密。

### Core Vision

| 维度 | 内容 |
|------|------|
| **Problem** | 42,000+ Agent 被攻破，88% 泄露涉及凭证。AI Agent 需要访问用户账户（Gmail、Notion、GitHub 等），但传统凭证管理方案不安全：明文存储、过度权限、缺乏审计。 |
| **Impact** | 企业级风险（平均泄露成本 $445 万）、合规困境（GDPR/CCPA/SOC2 要求凭证保护）、规模化障碍（62% 企业实验 AI Agent 但无法安全部署）。 |
| **Limitations of Existing Solutions** | 传统密码管理器（1Password/Bitwarden）：为人类设计，不支持程序化访问；Vault/云 HSM：企业级但复杂，不适合 Agent 场景；云厂商 Secrets Manager：集中式信任，不支持零知识。 |
| **Our Solution** | CredBridge 是 AI 原生的零信任凭证保险库：TEE+Rust 架构（密钥永不出安全飞地）、零暴露（Agent 仅获有限 Scope Token）、AI 原生（SDK 无缝集成 Agent 框架）、合规就绪（审计日志 + HITL 人工审批）。 |
| **Differentiators** | TEE+Rust 架构（内存安全 + 硬件级保护）、零暴露（凭证永不清解密到内存）、AI 原生（为 Agent 工作流设计）、合规就绪（从第一天起按企业标准构建）。 |

### 3 年愿景（2029）
- 10 万 + 开发者，5000+ 企业客户
- FIPS 140-2 Level 3 认证
- 年收入 $5000 万+，估值 $5 亿+

## Target Users（目标用户）

### Primary Users

#### 1. AI Agent 开发者/工程团队（最高优先级）

**角色画像：**
- 在 AI 初创公司或企业 AI 团队中开发 Agent 应用的工程师
- 具备较强的技术背景，熟悉 API 集成和凭证管理
- 对安全性和开发效率都有较高要求

**核心痛点：**
- 需要安全地存储和使用用户凭证，但现有方案（传统密码管理器、Vault 等）不支持 Agent 场景
- 缺乏适合程序化访问的安全凭证管理方案
- 担心凭证泄露导致的安全事故和合规问题

**关键需求：**
- 程序化访问接口（SDK/API）
- 有限 Scope Token（最小权限原则）
- 完整的审计日志
- 易于集成到现有 Agent 工作流

**付费意愿：** 高（安全是刚需，直接影响产品上线时间和合规性）

#### 2. 企业安全工程师/安全团队（高优先级）

**角色画像：**
- 负责企业 AI 安全合规的安全专业人员
- 关注合规认证、风险控制和审计要求
- 62% 的企业正在实验 AI Agent，但无法安全地规模化部署

**核心痛点：**
- 企业希望部署 AI Agent，但缺乏安全的凭证管理基础设施
- 现有方案无法满足企业级安全合规要求
- 担心数据泄露、未授权访问等安全风险

**关键需求：**
- 零知识架构（Zero-Knowledge Architecture）
- 合规认证支持（SOC2、FIPS、HIPAA 等）
- 人工审批工作流
- 细粒度的访问控制和审计追踪

**付费意愿：** 高（企业安全预算充足，合规驱动采购决策）

## MVP Scope

### 核心功能（Must Have）

**MVP 必须交付的核心功能：**

- **TEE 凭证保险库**
  - 基于 Rust + SGX/TEE 的零知识凭证存储
  - 凭证加密存储，密钥永不出 TEE
  - 支持 API/SDK 程序化访问

- **有限 Scope Token 系统**
  - 支持创建有时间/权限限制的 Token
  - 最小权限原则（Least Privilege）
  - Token 自动过期和轮换

- **审计日志**
  - 所有凭证访问操作记录
  - 不可篡改的日志存储
  - 基础查询和导出功能

- **基础 SDK（TypeScript + Rust）**
  - TypeScript SDK（Node.js 22+）
  - Rust SDK（后台集成）
  - 基础文档和示例代码

### MVP 边界（Not in MVP）

**明确说"不"的功能：**

- ❌ 企业级 SSO/SAML 集成
- ❌ 多租户团队协作功能
- ❌ 高级合规认证（SOC2/FIPS 等）
- ❌ 人工审批工作流（HITL）
- ❌ 多 TEE 平台支持（仅支持 SGX）
- ❌ 图形化管理界面（仅 API/CLI）
- ❌ 第三方集成市场

**有了更好但不是必需的：**

- ⚡ 图形化 Dashboard
- ⚡ 多 TEE 平台支持（TDX、SEV 等）
- ⚡ 高级分析和报表
- ⚡ 自动化合规报告
